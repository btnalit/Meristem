# word-count

This organ provides the capability to count whitespace-separated words in an arbitrary text string, exposed via a simple stdin-JSON / stdout-JSON ABI (input `{"text": "..."}`, output `{"words": N}`). Its utility is measured by two metrics declared in the manifest: **usage** (how often the organ is invoked by the kernel or by other organs) and **success_rate** (the fraction of invocations that exit 0 with valid JSON output). It should be pruned — moved to `deprecating` and then `archive` — when usage falls to zero across a sustained window (no caller depends on it), when its success_rate drops below an acceptable threshold and cannot be recovered by mutation, or when a successor organ subsumes word-counting as part of a broader text-statistics capability and the dependency graph has fully migrated to that successor.
