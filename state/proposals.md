- [ ] EXTERNALIZE: Move the review gate from meristem/gates/review.py (196 LOC) into body/organs/review-gate/. The review gate evaluates candidate mutations against review criteria and returns structured pass/fail verdicts with reasons — a self-contained capability that fits the organ pattern already established by failure-aggregator and selfcheck-runner. Moving it out of the kernel reduces core pressure by ~196 lines (2999 → ~2803, restoring headroom) and closure pressure by the same amount (39120 → ~38924). The organ would accept a mutation diff plus review criteria as input, return a verdict with reasons, and be invoked by the loop's gate orchestration via the same mechanism used for other externalized gates. This is a REPAIR for the core pressure crisis (2999/3000, one line from refusal) and also GROWTH since it demonstrates the gate-externalization pattern can be applied beyond the already-externalized failure-aggregator, making future gate additions budget-neutral.
- [ ] REPAIR (FA-011): Fix meristem/breaker.py should_park to fail loud when the journal path is missing or unreadable, instead of silently defaulting to False (retry). When _read_jsonl returns an empty list due to a missing or unreadable journal, should_park must raise or return a distinct error state that produces a fault record. Measurable: a missing journal should produce a fault record in the journal, not a silent retry.
- [ ] GROWTH: Add a probe that verifies each organ's selfcheck actually exercises its core logic. The probe runs each organ's selfcheck and checks that the output includes data that could only come from the organ's primary function (e.g., classification results for the failure-aggregator, edge/node data for the memory-graph). This catches the failure-aggregator case (FA-019) where the selfcheck was weakened to not test classification. Measurable: the probe should fail when an organ's selfcheck doesn't exercise its primary function.
