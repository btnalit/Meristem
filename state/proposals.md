- [ ] EXTERNALIZE: Move the review gate from meristem/gates/review.py (196 LOC) into body/organs/review-gate/. The review gate evaluates candidate mutations against review criteria and returns structured pass/fail verdicts with reasons — a self-contained capability that fits the organ pattern already established by failure-aggregator and selfcheck-runner. Moving it out of the kernel reduces core pressure by ~196 lines (2999 → ~2803, restoring headroom) and closure pressure by the same amount (39120 → ~38924). The organ would accept a mutation diff plus review criteria as input, return a verdict with reasons, and be invoked by the loop's gate orchestration via the same mechanism used for other externalized gates. This is a REPAIR for the core pressure crisis (2999/3000, one line from refusal) and also GROWTH since it demonstrates the gate-externalization pattern can be applied beyond the already-externalized failure-aggregator, making future gate additions budget-neutral.
- [ ] EXTERNALIZE: Move the deterministic gate from meristem/gates/deterministic.py (245 LOC) into body/organs/deterministic-gate/. The deterministic gate validates kernel size, closure pressure, and other deterministic invariants — it is the largest gate file and a natural organ candidate, since gates are already partially externalized (germline_validate.py at 66 LOC, closure.py at 181 LOC). The organ would expose a single op that reads the current kernel state and returns pass/fail with reasons, replacing the in-kernel gate call. This lowers core pressure by 245 lines (2999→2754) and closure pressure by 245 lines (39120→38875), giving headroom for the next mutation without touching the cap.
- [ ] EXTERNALIZE: Move the closure gate from meristem/gates/closure.py (181 LOC) into body/organs/closure-gate/, reducing core pressure by 181 lines and closure pressure by the gate's closure footprint. The gate's validation logic is self-contained and can be invoked as an organ from loop.py via a thin wrapper, following the same pattern as the already-proposed review and deterministic gate externalizations.
