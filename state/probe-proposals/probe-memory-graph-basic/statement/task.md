The memory-graph organ must, when invoked over its ABI with op "build", extract nodes from Meristem's state records (patterns, gaps, backlog, journal cycles), derive typed edges between them, and return node and edge counts. When invoked with op "stale" and a threshold, it must return a ranked list of nodes whose activation has fallen below that threshold, where activation decays with cycle age since last_seen_cycle and is reinforced by inbound edges from nodes seen more recently. A node last seen many cycles ago must rank as staler than one seen recently, and a node with a fresh inbound edge must not appear in the stale list below a threshold its reinforcement would lift it above.
